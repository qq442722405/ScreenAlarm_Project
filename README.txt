屏幕数值监控报警-Windows

说明：
1. 本工程的坐标拾取功能采用独立模态拾取窗口。
2. 点击“拾取坐标”后，左键选择屏幕位置；ESC取消。
3. 拾取完成后坐标会同步写回当前“添加点击”步骤，再点击确定即可保存。
4. “添加点击”支持移动到 X/Y 后执行左键或右键。
5. GitHub Actions 为手动触发打包（workflow_dispatch），不会因为提交自动打包。


【激活机制】
程序启动时会先验证设备识别码与激活码。未激活、激活码错误或已过期时不会创建主界面，也不会启动 OCR、网页服务、F12 监听等后台功能。激活成功后才进入主程序。

【防绕过设计】
- 激活码与 Windows MachineGuid、系统盘卷序列号绑定。
- 每次启动重新验证激活码及有效期。
- 激活验证放在主窗口创建之前，关闭激活窗口不能进入主程序。
- 激活信息与设备识别码绑定，复制到其他电脑无效。
- 激活码签名使用 HMAC-SHA256。

说明：纯离线授权无法做到绝对防破解；如果需要更高强度的商业授权，建议把签名私钥放在服务端，客户端只保留公钥并在线验证。
